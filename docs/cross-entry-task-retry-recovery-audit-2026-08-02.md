# 跨入口任务重试请求恢复审计（2026-08-02）

## 1. 本轮解决的工作问题

任务中心已经能判断“重试请求被拒绝”和“响应结果不确定”，但日常排障更常从工作台、实例详情或
主机恢复页直接开始。同一个 `409 resource_conflict` 在这三个入口仍分别表现为瞬时通用提示、通用
错误条和主机专用错误，操作者无法稳定确认是否创建了新任务、资源是否改变、哪个任务正在阻塞以及
何时可以安全重试。

本轮把任务中心的证据门槛作为唯一模型复用到四个入口，不改变服务端任务创建、权限、审计、备份、
生命周期或 SSH/Compose 执行语义。

## 2. 真实页面基线

基线在隔离 PostgreSQL 控制平面中使用合成主机、实例和任务完成。主机地址使用文档专用的
`192.0.2.0/24`；没有连接公司主机、执行 SSH、启动 Compose、修改真实数据库或运行破坏性操作。

| 入口与步骤 | 操作次数 / 跳转 | 重复输入 | 基线健康度 | 主要断点 |
| --- | --- | --- | --- | --- |
| 工作台待处理事项点击“重试任务” | 1 / 0 | 无 | 不健康 | 只显示“任务操作未完成”，原重试仍可再次点击；必须去任务中心查阻塞任务。 |
| 实例详情失败面板点击“重试任务” | 1 / 0 | 无 | 不健康 | 只显示瞬时通用错误；轮询虽会出现活动任务，但没有说明本次请求未入队、实例与数据未改变。 |
| 主机恢复页点击“重试原任务” | 1 / 0 | 无 | 不健康 | 错误持续可见，但文案错误地只说明“实例状态未改变”，缺少稳定错误码、阻塞任务和证据刷新门槛。 |
| 冲突解除后继续 | 至少 2 / 1 或更多 | 无 | 阻断 | 三个入口需要凭经验刷新、跳转任务中心、重新定位原失败任务，无法原地判断是否可安全重试。 |

### 问题分级

- P0：本轮未发现新的越权、重复任务或数据破坏风险。服务端运维权限与活动资源任务唯一索引仍会拒绝
  并发任务，因此重复按钮没有绕过最终写边界。
- P1：三个高频入口没有复用任务中心的后继任务识别、阻塞任务证据和安全重试门槛，显著增加页面往返
  和故障确认时间。
- P1：主机恢复入口对非实例任务使用实例专用影响文案，可能让操作者误判主机任务的影响范围。
- P1：网络结果不确定时，三个入口没有要求两次成功证据读取，存在盲目重复提交的诱因。
- P2：同一错误在不同页面使用不同标题、信息层级和按钮顺序，增加学习成本。

## 3. 可观察验收标准

1. 工作台、实例详情、主机恢复页和任务中心展示相同的原因、影响、恢复建议、错误码和当前阻塞任务。
2. 所有入口都读取不受页面筛选影响的 `/tasks` 证据，并按操作链、任务类型、资源和请求时间寻找后继任务。
3. 存在活动阻塞任务时，原重试入口隐藏或禁用；操作者可以原地打开当前任务和对应资源。
4. 稳定服务端拒绝在阻塞解除并刷新证据后开放重试；网络不确定结果至少需要两次成功证据读取。
5. 权限不足、任务不存在、参数无效或任务不再可重试时不开放重试；只读角色仅查看非敏感证据。
6. 找到后继任务或请求成功后，页面清除旧请求提示并回到新任务的标准跟踪状态。
7. 中文 1440px、英文 1024px 下没有悬空按钮、重复标题、遮挡、横向溢出或控制台错误。

## 4. 实现结果

- 新增共享 `useTaskRetryRequest` 状态机，统一提交失败、未筛选任务证据读取、刷新次数、后继任务跟踪、
  当前阻塞任务和加载错误。
- 新增共享 `TaskRetryRequestRecovery` 面板，四个入口使用相同的原因、影响、恢复建议、错误码、阻塞任务
  和操作层级。
- 工作台保留当前待办上下文；实例详情保留当前实例上下文；主机恢复页继续维护 `host` 与
  `recoveryTask` 链路；任务中心找到后继任务后直接打开新任务。
- 主机恢复页删除专用的通用重试错误，避免错误地把主机任务影响描述成实例状态变化。
- 只读权限继续由现有前端角色模型隐藏写入口，服务端运维权限仍是最终边界。

## 7. 证据边界与后续风险

- 本轮验证的是控制平面和真实页面，不代表真实公司网络、SSH、Docker Compose 或数据库进程已经验证。
- 后继任务通过隔离控制平面合成成功终态，避免任务工作器连接文档专用地址；真实执行时序仍需在授权的
  可丢弃测试主机上按内部试用清单验证。
- `/tasks` 证据当前最多返回最近 100 条。证据不足会保持阻断而不会错误开放重试，但高任务量试用时应记录
  是否出现需要更精确资源证据接口的情况。
- 下一轮优先审计故障恢复后“返回实例确认状态 → 连接信息交付”的最后一段是否仍需要页面往返或人工核对。
